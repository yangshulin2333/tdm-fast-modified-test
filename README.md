# TDM Fast 1.0.0 修改测试版

中文 | [English](README_EN.md)

## 使用

1. 完全退出所有 TDM Fast 进程，包括托盘中的程序。
2. 将 ZIP 完整解压到一个新的可写目录；不要覆盖原安装目录，也不要直接在压缩包内运行。
3. 双击 `Launch.cmd`。它使用包内 `UserData` 目录保存独立配置；首次启动请检查下载目录。
4. 原版与测试版不要同时运行，它们使用相同的本地端口 `37651`。

### Chrome 扩展（可选）

打开 `chrome://extensions/` → 开启“开发者模式” → “加载已解压的扩展程序” → 选择解压目录中的 `resources/extension`。启动桌面程序后刷新目标网页。Chrome 扩展的完整下载流程尚未验证。

### 恢复原版

退出程序后运行 `Restore-original.cmd`，恢复包内原始 `app.asar`。恢复后需要原版激活；该脚本保留用户配置及下载文件。包内不含原版卸载程序。
