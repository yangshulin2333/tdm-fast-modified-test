# Chrome 插件安装与使用

[English](CHROME_EXTENSION_EN.md) · [返回首页](../README.md)

## 1. 下载插件

[点击下载独立插件 ZIP](https://github.com/yangshulin2333/tdm-fast-modified-test/releases/download/v1.0.0-test.1/TDM-Fast-Chrome-extension-4.0.0.zip)

插件名称为 **TDM Fast 资源嗅探**，插件版本 **4.0.0**；桌面程序版本是 1.0.0，二者版本号不同是正常的。此包直接提取自已发布的完整包，插件代码未修改。插件界面沿用中文，英文版教程提供按钮对照。

已经下载完整桌面包的人，可以直接使用其中的 `resources/extension`，无需重复下载。插件需要正在运行的 TDM Fast 桌面程序来接收下载任务，不能替代桌面程序。

## 2. 解压到固定目录

右键 ZIP → **全部解压缩**，保留里面的 `extension` 文件夹。不要双击 ZIP 后直接尝试加载，也不要安装后删除或移动该目录。

应选择的文件夹结构如下（关键是同一层能看到 `manifest.json`）：

```text
extension/              ← Chrome 中选择这一层
├── manifest.json
├── background.js
├── content.js
├── inject.js
├── popup.html
├── popup.js
└── icons/
```

## 3. 在 Chrome 中安装

1. 在 Chrome 地址栏输入 `chrome://extensions/`，按回车。
2. 打开右上角 **开发者模式（Developer mode）**。
3. 点击 **加载已解压的扩展程序（Load unpacked）**。部分版本显示“加载已解压缩的扩展程序”。
4. 选择上一步的 `extension` 文件夹，不要选 ZIP，也不要选上一级目录。
5. 页面出现 **TDM Fast 资源嗅探 / 4.0.0** 卡片，并处于启用状态，即完成加载。
6. 点击浏览器右上角拼图图标，在插件旁点击图钉，将它固定到工具栏。

```text
解压 ZIP → 打开扩展管理页 → 开启开发者模式 → 加载 extension 文件夹
```

## 4. 第一次使用

1. 完全退出其他 TDM Fast 实例，再通过完整桌面包中的 `Launch.cmd` 启动程序。
2. 回到要下载资源的普通网页，刷新页面；若是视频，先开始播放，再打开插件。
3. 点击工具栏中的插件图标，勾选列表中的资源，再点击 **下载所选**。
4. 切换到桌面程序，确认任务实际出现并查看结果。“已发送”提示本身不证明文件下载成功。

也可以右键网页中的链接，选择 **使用 TDM Fast 下载此链接**。弹窗中的 **接管浏览器下载** 开关控制自动接管；点击齿轮可设置文件类型、大小门槛和网站黑名单。首次尝试可以先关闭自动接管，手动选择一条资源下载。

## 5. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到 manifest 或无法加载 | 确认已解压，选择直接包含 `manifest.json` 的文件夹；保留所有脚本和 icons 目录 |
| 没有“加载已解压”按钮 | 确认开发者模式已开启；单位管理的浏览器可能限制加载扩展 |
| 当前页面暂未嗅探到资源 | 刷新普通网页，播放视频后重试；浏览器设置页等内部页面不能作为测试页面；并非所有站点均可识别 |
| 发送失败 | 确认桌面程序正在运行；插件向本机 `127.0.0.1:37651/capture` 发送任务，不要同时启动多个桌面实例 |
| 不想自动接管下载 | 在插件弹窗取消勾选“接管浏览器下载” |
| 移动目录后插件报错 | 在扩展管理页移除旧条目，再从新位置加载 |

## 6. 更新与卸载

更新：退出相关页面，将新版解压到固定目录，在 `chrome://extensions/` 点击插件卡片的重新加载按钮，再刷新网页。

卸载：在扩展管理页找到插件，点击 **移除（Remove）**，之后可以删除解压目录。

## 权限与验证范围

清单申请了所有网站访问、网络请求观察、下载、标签页、存储、通知、右键菜单和导航相关权限，用于资源检测与下载接管。插件不是 Chrome 商店安装包，无需寻找 `.crx` 文件。

本次核验了插件与原完整包逐文件一致、ZIP 完整性及清单引用文件齐全；**尚未实测当前 Chrome 中的加载及浏览器到桌面的完整下载流程**。真实网站兼容性不保证；桌面程序的重启后续传已知问题仍然存在。

英语：**Load unpacked** = 加载已解压的扩展；**Pin to toolbar** = 固定到工具栏。
